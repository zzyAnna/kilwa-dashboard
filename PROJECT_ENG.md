# Kilwa Pipeline Dashboard

## Project Objective
Create a Dashboard to monitor and evaluate the performance of Kilwa's data processing and analysis pipelines, allowing stakeholders to view metrics without manually running code.

## Core Features

### 1. Web Scraper Health Monitoring
- **Metadata Completeness Check**: Null/non-null percentage for each field
- **Data Filtering**: Filter by source type (local news vs research reports, etc.)
- **Health Summary**: AI-generated scraper performance summary (optional, if time permits)

### 2. Sentiment Analysis Engine Comparison
- **Efficiency Metrics**: Time taken by FinBERT engine to process and output scores for each batch of articles
- **Model Comparison**: Compare FinBERT vs traditional model (VADER + TextBlob) by generating scores. Metric will be generated by taking the average difference between the two scores (e.g. does FinBERT consistently overscore or underscore, and how much deviation occurs)
- **Language Translation Accuracy**: Compare FinBERT performance for an article in its original language vs the translated version. Metric will be generated by taking the average difference between the two scores.
- **Manual Article Upload**: Manually upload an article of interest to test FinBERT vs traditional model output (e.g. if I pick an article that I know is very biased, what is the difference between the two engines?)

## Database Structure

### news_articles Table
```sql
- id: integer (primary key)
- country_id: integer (foreign key)
- title: text (title)
- content: text (content, can be NULL)
- summary: text (summary, can be NULL)
- source: varchar(100) (source)
- author: varchar(200) (author, can be NULL)
- published_at: timestamp (publish time)
- url: varchar(500) (link, can be NULL)
- sentiment_score: double precision (sentiment score)
- sentiment_label: varchar(20) (sentiment label)
- sentiment_confidence: double precision (confidence)
- topics: json (topics)
- relevance_score: double precision (relevance)
- processed_at: timestamp (process time)
- language: varchar(10) (language)
- word_count: integer (word count)
- created_at: timestamp
- updated_at: timestamp
- language_confidence: double precision
- was_translated: boolean (was translated)
- original_language: varchar(10)
- translation_confidence: double precision
```

## Existing Code Analysis

### SentimentAnalyzer (VADER + TextBlob)
- Location: `kilwa-backend-main/etl/transform/sentiment_analyzer.py`
- Function: Multi-language sentiment analysis, supports translation
- Interface: `analyze_article(title, content)` → returns sentiment_score, sentiment_label, sentiment_confidence

- Location: `kilwa-backend-main/etl/transform/finbert_analyzer.py`
- Function: Financial sentiment analysis based on FinBERT
- Interface: `analyze_text(text)` → returns sentiment_score, sentiment_label, confidence

### HybridSentimentAnalyzer
- Combines FinBERT and traditional methods
- Supported modes: hybrid, finbert_only, keywords_only
